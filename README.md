# HLK-FM22x + ESPHome + Home Assistant

Готовая конфигурация ESPHome для модулей распознавания лиц **Hi-Link HLK-FM223 / HLK-FM225**
с удобным управлением из карточки Home Assistant: регистрация лица по имени, введённому
прямо в интерфейсе, распознавание, удаление пользователей и хранение имён (модуль сам
имена при распознавании не возвращает).

Основана на официальном компоненте ESPHome [`hlk_fm22x`](https://esphome.io/components/hlk_fm22x/).

## Возможности

- Ввод имени нового пользователя прямо в Home Assistant, без правки конфига под каждого человека.
- Пошаговая регистрация лица (5 ракурсов: прямо, вправо, влево, вниз, вверх) с подсказками
  на экране и автоматическим перезапуском при неудачном кадре.
- Таблица соответствия `ID -> имя`, которая переживает перезагрузку платы (модуль HLK не
  возвращает имя при распознавании, только числовой ID).
- Удаление одного пользователя или всех сразу, тоже из карточки.
- Готовая карточка Home Assistant (`dashboard-card.yaml`).

## Оборудование

- ESP32 (проверено на ESP32-S3) с двумя свободными GPIO под UART.
- HLK-FM223 или HLK-FM225 (там же протокол, что и на всей серии FM22x).
- Отдельный источник питания для модуля.

## ⚠️ Важно про питание (особенно для FM225)

По даташиту модулям нужно **5.5–9V при токе ≥1A** на пин VCC — обычных 5V с пина платы или
из USB-порта компьютера может не хватать. У HLK-FM223 это часто "прощается" и модуль работает
и от заниженного напряжения, а вот **HLK-FM225 в таких условиях стабильно перезагружается**
прямо в момент включения камеры и ИК-подсветки (в логе это выглядит как полная тишина после
команды `enroll`/`scan`, а через 2–3 секунды - уведомление о том, что модуль снова "готов").

Если сталкиваетесь с тем, что регистрация или сканирование всегда виснут и обрываются
таймаутом (`Command 0x13/0x12 timed out`) - в первую очередь проверьте, что на VCC модуля
подано напряжение именно из диапазона 5.5–9V, от отдельного источника, а не от 5V-пина платы
или через USB компьютера. В нашем случае именно это оказалось причиной, и после подключения
блока питания 6-9V проблема исчезла полностью, без единой перезагрузки.

Провода питания - короткие и толстые, землю модуля обязательно соединить с землёй платы ESP32.

## Пины UART

```yaml
uart:
  rx_pin: GPIO12   # <- TX модуля
  tx_pin: GPIO13   # -> RX модуля
```

Пины можно менять на любые свободные GPIO (кроме strapping-пинов и занятых под
флеш/PSRAM/USB - зависит от конкретной платы).

## Установка

1. Создайте рядом с конфигом файл `secrets.yaml` со своими значениями:
   ```yaml
   wifi_ssid: "your_wifi_name"
   wifi_password: "your_wifi_password"
   ota_password: "your_own_random_password"
   ap_password: "your_own_random_password"
   ```
   Пароли для `ota_password` и `ap_password` сгенерируйте сами, например:
   ```bash
   python3 -c "import secrets; print(secrets.token_hex(16))"
   ```
   `secrets.yaml` не должен попадать в git - используйте `.gitignore`.
2. Пропишите нужные вам `rx_pin`/`tx_pin`, если они отличаются от GPIO12/13.
3. Пропишите питание модуля отдельным источником (см. раздел про питание выше).
4. Прошейте плату через [ESPHome](https://esphome.io/):
   ```bash
   esphome run face-recognition.yaml
   ```
5. Добавьте устройство в Home Assistant (обычно через автоматическое обнаружение).
6. Импортируйте `dashboard-card.yaml` в качестве карточки типа "Entities", заменив
   `face_recognition_...` в ID сущностей на реальные ID вашего устройства (Home Assistant
   иногда добавляет к ним префикс области/комнаты - проверьте в Настройки → Устройства).

## Известные ограничения

- Тайм-аут одного шага регистрации жёстко зашит в самом компоненте ESPHome и равен 10
  секундам - через YAML не настраивается. Вставайте перед камерой ДО нажатия кнопки
  регистрации, а не после.
- Значение `direction` в протоколе FM22x - это одно значение (1/2/4/8/16), а не сумма
  битов. Отправка "суммы" (например 31, чтобы записать "все ракурсы сразу") не
  поддерживается протоколом.
- Имя пользователя должно быть латиницей, без символов `;` и `=` (они служебные во
  внутренней таблице имён), максимум 20 символов.
- Список имён хранится в одной текстовой сущности (лимит 255 символов), этого хватает
  примерно на 10-15 человек.
